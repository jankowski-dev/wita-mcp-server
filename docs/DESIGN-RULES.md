# Правила проектирования (уроки пользователя)

Собираются в процессе совместной работы. Генератор шкафов обязан им следовать.

## Членение шкафа

- Шкаф **длиннее 1 м — делить на секции** (модули) примерно по 1200 мм.
  Каждая секция — самостоятельный корпус со своими боковинами.
- В секции — 2 отделения (перегородка внутри).

## Корпус

- **Верх и низ — накладные, одной деталью на секцию** (1200 мм целиком).
- Боковины и перегородки — **внутри**, между верхом и низом
  (высота = H − 2×толщина).
- Задняя стенка накладная не делается: **ХДФ в пазе**.
  Стандарт паза: ширина 4 мм, глубина 8 мм, отступ от задней кромки 10 мм.
  Материал ХДФ — «ХДФ белая» (3 мм). Кромкой ХДФ не оклеивается.

## Полки

- Крепление — **конфирмат через боковину/перегородку в торец полки**
  (горизонтально). Порядок `Mount(полка, боковина, …)` — иначе сядет на кромку.
- В ящичных отделениях — полка над блоком ящиков.

## Ящики

- Блок ящиков **обрамляется в корпус** — фасады ящиков **меньше** ширины проёма
  на толщину обвязки (по 16 мм с каждой стороны) и **утоплены по глубине на 16 мм**:
  дверь не мешает выдвижению.
- Типовой размер: 3 ящика по 250 мм.
- Корпус ящика: боковины/дно/задняя/передняя стенка; фасад — вкладной.
- **Петли на двери в зоне обвязки блока ящиков не ставить** (пересечение).

## Двери

- По одной накладной двери на каждое отделение.
- Толщина 16, зазоры 4 мм между дверями, 2 мм по краям.
- Петли: `Mount(боковина, дверь, 32, высота, 0)`; чашка — в дверь.
  - вешалочные двери: 100 / 1250 / 2400 мм;
  - ящичные двери: только **выше блока** — 900 / 1650 / 2400 мм.

## Кромка

- ЛДСП-панели — по периметру (4 стороны), материал по умолчанию из базы.
- Фасады ящиков и двери — по периметру.
- Внутренние детали — по стандарту (уточняется).

## Материалы (у пользователя)

- ЛДСП: дефолт базы (в тестах — «H1399 ST10 Дуб Денвер трюфель»), 16 мм.
- ХДФ: «ХДФ белая», 3 мм.
- Кромка: дефолт базы (в тестах — «F433 ST10 Лён антрацит», 2×35 мм).
- Крепёж: конфирмат («Евровинт 6х50»).

## Открытые вопросы

- Стандарт кромки для внутренних деталей (видимые/невидимые стороны).
- Цоколь/опоры — не проработаны.
- Штанга: нужен файл трубы `.f3d`; держатели HA10 уже ставятся.
