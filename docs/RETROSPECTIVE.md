# Ретроспективный аудит изменений WITA MCP — сессия 09–20.11.2026

Цель: честная оценка всех изменений сессии (worker, операции, документация,
модель, репозитории), список дефектов и приоритетные исправления.

## 2. Сильные стороны

1. **Верификация по фактам**: каждая мутация возвращает read-back (Position,
   ContourWidth/Height, cutsCount) — не «поверил на слово».
2. **Знание движка добыто probe'ами** (v2/v3/v5), а не догадками: правила
   «обёртка умирает на коммите», «GMin/GMax не обновляются», «контуры 0-based».
3. **Безопасность**: белый список ops, guard «Габаритная рамка», правило
   удаления по индексам для дублей имён.
4. **Честные откаты**: resize с авто-восстановлением, copy recreate вместо
   мёртвого Clone, cut_delete.
5. Скиллы и KB: реальная база знаний с каталогами производителей.

## 4. Оценки

| Критерий | Оценка | Комментарий |
|---|---|---|
| Инженерная корректность кода | **B+** | verification-first, но pockets-семантика не доказана визуально |
| Надёжность/безопасность | **B+** | guard'ы и правила есть; единичные потери при чистке |
| Процесс (рестарты/деплой/версии) | **C+** | основная зона роста |
| Документация | **B** | синхронно, но с лагами (ops-описания, fasteners_spec) |
| Знания/RAG | **A-** | каталоги загружены, KB пересобран, скиллы валидированы |
| Состояние модели | **B-** | чисто; 1 потерянный евровинт; тестовые следы убраны |
| **Итог** | **B** | технически зрело, процесс требует дисциплины |

## 5. Топ-5 исправлений до Ф2

1. **Push репозиториев** (сеть восстановить): code 1 ahead, knowledge 7 ahead.
2. **tools/deploy-worker.ps1**: одномоментно — `node --check` + non-ASCII=0 +
   сверка версии + копирование + md5 + вывод «что задеплоено»; запретить деплой
   при несоответствии. Рестарт просить ТОЛЬКО после успешного скрипта.
3. **fasteners_spec v2**: ключи D1/D2/D3, поле `depth` → `width`, добавить
   позиции фасадов/Bottom (для зазоров), заглушить шум.
4. **Правило батарей**: тестовые вырезы — только на scratch-панели или
   авто-удаление в том же вызове; пользовательские панели — read-only по умолчанию.
5. **Доки**: OPERATIONS — probe_*/fasteners_spec; server description — актуальный
   список ops; STP-MK1 — пометка «числа для сверки», без догадок.

## 6. Вывод

Изменения **работоспособны и проверены**: 11 версий worker'а доведены до
согласованного API, все ключевые операции имеют верификацию, документация и
знания наполнены. Главные риски — не код, а **процессная дисциплина**
(рестарты, ASCII, версии, синхронизация репозиториев) и **недоказанная
визуально семантика карманов**. После топ-5 исправлений — можно двигаться в
Ф2 (фаски/STP) без накопления долга.
