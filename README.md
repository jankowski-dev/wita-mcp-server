# WITA MCP Server

MCP-сервер, который даёт ИИ-агенту (OpenCode и любому MCP-клиенту) возможность
**читать и изменять модель САПР**: дерево модели, панели,
материалы, кромка, крепёж, фурнитура, пакетные операции.

> Главная идея: БАЗИС не имеет внешнего API, поэтому внутри программы работает
> «worker»-скрипт. MCP-сервер общается с ним через файловый ящик
> `C:\Users\Public\basis-mcp`. Один запуск worker'а за сессию БАЗИС — дальше всё
> автоматически: команды исполняются за ~2 секунды, без нажатий.

## Возможности

| Категория | Операции |
|---|---|
| Чтение | дерево модели, свойства панелей (материал/толщина/контур/кромки), выделение, позиции объектов |
| Панели | создание (front/horiz/vert), удаление, переименование, материал, толщина |
| Кромка | наклейка по элементам контура (`AddButt`) |
| Крепёж | конфирматы между панелями, на плоскость |
| Фурнитура | `.f3d` из библиотеки: петли, полкодержатели, штанги и т.д. |
| Пакетно | массовая замена материала с dry-run |
| Группировка | блоки (`BeginBlock/EndBlock`) — в дорожной карте |

## Установка

Полная пошаговая инструкция (MCP + worker + скиллы, второй ПК):
**[docs/INSTALL.md](docs/INSTALL.md)**. Кратко:

1. Склонировать репозиторий и `npm install` в `server/`.
2. `tools\install-worker.ps1` — скопирует скрипты в папку БАЗИС.
3. `opencode.json`: сервер `basis` (абсолютные пути) + `"skills": ["<путь>\\wita-mcp-knowledge\\skills"]`.
4. БАЗИС → «Скрипты» → `0_BasisMCP_worker`.
5. Проверка: `basis_status` → `worker-listening`.

## Быстрый старт

```text
«Покажи дерево модели»
«Создай панель 800×600, материал по умолчанию, имя "Полка"»
«Проклей кромку у панели Shelf-1 по всем сторонам»
«Замени у всех панелей материал на ЛДСП Белый (сначала dry-run)»
«Поставь 3 конфирмата между Side-L и Bottom»
```

## Безопасность

- Агент исполняет **только белый список операций** — произвольный код в БАЗИС
  не попадает.
- Скрипты не сохраняют модель автоматически; все изменения в истории (undo).
- Обмен — через локальную папку `C:\Users\Public\basis-mcp` с атомарной записью.

## Известные ограничения

- Запуск worker'а — вручную (1 клик в меню) из-за защиты БАЗИС от синтетического
  ввода; дальше сессия живёт самостоятельно.
- Смерть сессии: ESC, запуск другого скрипта, перезапуск БАЗИС. Очередь не теряется.
- Выбор конкретного материала кромки по имени — через интерактивный пикер
  (программно пока не подтверждён).
